# DatingApp-net8

**The world's most amazing demo SPA**

DatingApp-net8 is a full-stack Single Page Application (SPA) built with ASP.NET Core 8 and Angular 17. It serves as a demonstration of modern web development practices, showcasing features like user authentication, profile management, and real-time messaging.

## Features

- **User Authentication**: Secure registration and login functionalities.
- **Profile Management**: Users can create and manage their profiles.
- **Real-time Messaging**: Instant messaging between users.
- **Responsive Design**: Paging, Sorting and Filtering.
- **RESTful API**: Backend services built with ASP.NET Core 8.

## Technologies Used

- **Frontend**: Angular, TypeScript, HTML, CSS
- **Backend**: ASP.NET Core 8, C#
- **Database**: Entity Framework Core
- **Development Tools**: Visual Studio Code, .NET CLI, Angular CLI, NPM

## Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [Node.js and npm](https://nodejs.org/)
- [Angular CLI](https://angular.io/cli)

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/mahee1981/DatingApp-net8.git
   cd DatingApp-net8
   ```

2. **Set up the backend**:

   ```bash
   cd API
   dotnet restore
   dotnet build
   dotnet run
   ```

3. **Set up the frontend**:

   ```bash
   cd client
   npm install
   ng serve
   ```

4. **Access the application**:

   Open your browser and navigate to `http://localhost:4200`.
